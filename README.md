# 基于SpringBoot+Vue3的旅游购票系统

![Spring Boot](https://img.shields.io/badge/-Spring%20Boot-6DB33F?style=flat-square&logo=spring-boot&logoColor=white) ![Vue3](https://img.shields.io/badge/-Vue3-grey?style=flat-square) ![ElementPlus](https://img.shields.io/badge/-ElementPlus-grey?style=flat-square) ![MySQL](https://img.shields.io/badge/-MySQL-4479A1?style=flat-square&logo=mysql&logoColor=white) 

## 项目介绍

本系统是一个功能完善的旅游购票管理平台，面向毕设、课设和学习场景开发；系统分为用户端和管理后台两个部分，用户端提供景点浏览、门票预订、旅游攻略、周边住宿等核心功能，管理后台则提供景点管理、订单管理、用户管理等运营管理功能。

## 功能模块

- **景点管理**：景点信息展示、分类筛选、智能搜索、景点详情查看与收藏
- **门票预订**：多种票型选择、在线预订、订单管理、支付功能
- **旅游攻略**：用户发布攻略、攻略列表展示、攻略详情浏览
- **周边住宿**：住宿推荐、多条件筛选（类型/价格/评分）、住宿详情与评价
- **用户中心**：个人信息管理、我的订单、我的收藏、我的攻略
- **后台管理**：用户管理、景点管理、分类管理、评论管理、门票管理、订单管理、住宿管理、攻略管理

## 技术架构

- **后端**：Spring Boot 2.7.18 + MyBatis-Plus 3.5.3.1 + Spring Security + JWT认证
- **前端**：Vue 3 + Element Plus 2.9.4 + Vue CLI 5 + Pinia + Vue Router 4
- **数据库**：MySQL 8.0
